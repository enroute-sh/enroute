# Agent Guidelines for Enroute

## Rules

- Read the minimal local context required for the task.
- Keep changes scoped and avoid unrelated refactors.
- When writing comments or documentation, strictly follow the Google Developer Documentation Style Guide (https://developers.google.com/style). Write in a plain, formal register: address the reader as "you", write steps in the imperative, use few contractions, and state limits and points of no return as facts, without alarm words.
- Keep comments extremely brief. Explain WHY, never WHAT. If it just restates the code or narrates history, it's not needed.
